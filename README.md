# 發展遲緩／早期療育主題站：資料來源盤點（v0）

2026-09-11 整理。目的：評估「發展遲緩兒童早期療育資源」能否套用 seh.tw v2 機制做成主題站。核心假設：家長最缺的不是名錄，而是「哪裡可以評估、等多久、什麼時候放名額、之後去哪療育、有什麼補助」的**一張地圖加時間軸**。

標「⚠ 待驗證」者只看過搜尋結果或網頁外觀，尚未親自抓過。

> **全部來源的清單、取得方式與更新頻率彙整在 [`research/DATA-SOURCES.md`](research/DATA-SOURCES.md)**（含建議抓取節奏與共通踩雷）。
>
> **2026-09-11 實測結果見 [`research/2026-09-11-sources/README.md`](research/2026-09-11-sources/README.md)**。其中 §2 列出本文件需要更正的地方。一句話收斂：**「地圖」與「年齡時間軸」兩半的資料都齊全**（檢核表 13 個年齡層、健康手冊 9 個時段、國健署 9 份分齡量表都拿得到）；拿不到的只有「等多久」——各中心的等候天數沒有任何公開來源。
>
> **教育素材（照顧者／被照顧者／朋友三方）見 [`research/2026-09-12-education/README.md`](research/2026-09-12-education/README.md)**。最大的空缺：沒有任何官方素材是向孩子本人解釋評估與療育流程的。
>
> **性平、兒少保、特教三個相鄰領域見 [`research/2026-09-12-topics/README.md`](research/2026-09-12-topics/README.md)**。可用的是兒少保統計（學齡前占受虐 24.7%）與縣市特教年報（唯一有行政區級發展遲緩人數）；性平教材對象是學齡後學生。

## 0. 一句話結論

名錄層已被社家署整理得相當完整（但只有名錄）；**等候與名額資訊存在但散在各醫院與各縣市衛生局，且每月覆蓋不留歷史**；統計層有官方年度數字可做供需對照。三種資料形狀（快照不留歷史／散在多機關／名錄與動態不相連）同時命中，是目前盤過的題目裡最強的一題。同時也是倫理邊界最需要先畫清楚的一題。

## 3. 資料形狀的實況與問題

| 現象 | 例子 | 對架構的意義 |
|---|---|---|
| 同一家醫院四處出現、寫法不同 | 社家署名錄、國健署 PDF、縣市衛生局頁、醫院自家頁 | cluster 規則：醫事機構代碼(1.0) → 全銜(0.95) → 簡稱+縣市(0.8) |
| 等候／名額是文字，每月覆蓋 | 「9 月名額 8/20 中午開放」下個月就被新公告蓋掉 | observation append-only，且要把「放名額日」解析成 event |
| 每家預約機制不同 | Line 預約、電話、每月定時線上釋出、不開放掛號 | `bookingMethod` 是必要欄位，不能只給電話 |
| 服務區域跨縣市 | 通報轉介中心「服務區域：全新北市」；有些療育單位收外縣市 | relation 要用「服務區域」而非只用地址縣市 |
| 正式與非正式 | 國健署補助聯評中心 vs 「其他經認可辦理評估之醫院」 vs 醫院自稱 | entity 要有 `tier`（重點／一般／認可／未列），來源是國健署 PDF |
| 名錄年更、動態月更、統計年更 | 三種節奏 | 健康檢查不能一套規則；名錄類用「消失即警示」，動態類用「超過 N 天未更新即標示過期」 |
| 補助規則 22 套 | 各社會局公告 | 用 override 檔人工維護，不做自動解析 |

## 4. 對應 seh.tw v2 架構

| seh.tw 概念 | 本題對應 | 差異 |
|---|---|---|
| Source ingest | 社家署名錄 1 支、國健署 PDF 1 支（年更）、各縣市衛生局 N 支、各聯評中心 89 支（可能按醫院網站模板歸併成十幾支） | 89 支小解析器是主要工程量；醫院網頁改版頻繁 |
| Observation | (中心, 抓取日) → 名額開放日、收案量、預約狀況、門診時段 | 每日抓，文字解析要保守，解析不到就存原文不填欄位 |
| Event | 名額開放時間點、療育補助申請截止 | 「本週放名額」入口 |
| Derived entity | 聯評中心、療育單位、通報／個管中心、治療所 | 有醫事機構代碼可用，比場館好連 |
| Relation | 中心→縣市、單位→服務區域、單位→類型、單位→補助方案、篩檢單位→通報中心→聯評→療育（旅程順序） | 「旅程順序」是本題特有的 relation，頁面上就是「下一步去哪」 |
| Quality score / noindex | 有座標、有預約方式、有 30 天內動態 → index；只有名錄 → 收錄但 noindex | 等候資訊必須顯示來源與抓取時間 |
| 靜態頁 | 縣市頁、行政區頁、單位頁、類型頁（聯評／到宅／語言治療）、「本週放名額」頁、旅程頁（我在哪一步） | 旅程頁是 seh.tw 沒有的頁型 |

## 5. 倫理與呈現邊界（先定，再開工）

1. **只到機構層級**：不碰個案、不收任何家長輸入的孩子資訊、不做社群。
2. **不做品質排名**：只呈現量能（收案量、家數）與等候（放名額日、預約狀況），不評「哪家評得好」。
3. **等候資訊一律標來源與時間**：家長會據此行動，過期資訊比沒有更糟；超過 N 天未更新自動標示。
4. **不取代通報轉介中心**：每頁都導回所屬縣市通報轉介中心；站是路標不是窗口。
5. **醫療名詞用官方用語**（發展遲緩、聯合評估、早期療育），不用診斷性描述。
6. 補助金額只列來源與連結，不自行試算。

## 7. 開工前要親自量的

1. ~~抓社家署 `resourceView` 各 `qtype` 的總筆數與欄位~~ **已完成**：13 個分類共 2,265 筆，無座標、無醫事機構代碼，也**沒有任何識別碼**（見下）。
2. ~~解析國健署 115 年名單 PDF~~ **已完成**：89 家（重點 16／一般 73），重點中心只用淺紅底標示、要讀色塊。
3. **網址問題已解決大半，逐站解析仍未做**：名錄原本只有 9/90 家聯評中心填了官網。改走**國健署的全國聯絡資訊 PDF**——一頁涵蓋 22 縣市共 51 家的電話與分機，51 家全部配得到醫事機構代碼；再把臺中與新北衛生局頁的連結欄展開，聯評中心的網址補到 **25/90**（新北 12 家全數補齊），全庫有官網的從 68 增為 84 家。`observation.csv` 已有 185 筆、涵蓋 89 家機構。

   衛生局頁的連結多是短網址，**`reurl.cc` 必須用瀏覽器才展得開**：它不含任何轉址語法（沒有 3xx、沒有 meta refresh、沒有 `location.href`），跳轉由 JS 執行後才發生，用 curl 剖 body 會誤抓成 favicon 的網址。`shorturl.at` 則是 Cloudflare 反機器人挑戰（403），不繞，臺中有 5 家因此留空。

   仍然沒做的是**逐站解析**：有了網址只是前提，放名額日這類只有醫院自己網頁才有的資訊，抽查 13 家仍只有 1 家公布，且每家頁面模板都不同。
4. 查 22 縣市衛生局是否有像新北那樣的「預約情況」頁——**查過 5 個，其餘 17 個還沒逐一查**。已解析進 `observation.csv` 的有新北、臺中、嘉義市三頁，**沒有一頁有等候天數或名額**：新北只有預約方式、臺中只有電話與分機（但標了初評／複評）、嘉義市是唯一附門診時間的。桃園也有同類頁，但 HiNetCDN 一律回 HTTP 428（防爬，不繞）；彰化有 PDF 版的評估單位一覽表。

   已查的 5 個縣市沒有一個提供等候資訊，這個結論目前看來穩定，但**不能當成 22 縣市都如此**——還沒查的 17 個裡若有縣市公布等候天數，那會是整個題目最值錢的一筆資料。
5. ~~查社家署通報概況是否有縣市級 CSV~~ **已完成**：統計處 2.5.4 有縣市×年×年齡的 xlsx，季更。
6. ~~抽三個縣市的療育補助公告~~ **22 縣市全部盤完**：19 套讀到官方原文、3 套（苗栗、澎湖、連江）官方沒把金額上網。規則寫在 [`research/scripts/subsidies.json`](research/scripts/subsidies.json)。入口是社家署的法規彙整頁，22 縣市的官方連結都在同一頁。

盤完之後浮出來的兩個問題，比原本列的六項更關鍵：

- **社福單位沒有穩定 ID**：1,896 家（占 62%）只能用「縣市＋名稱」當 key，改名就會被當成「一家消失、一家新增」，而名錄類的健康檢查規則正是「消失即警示」。補救是留住上一版再用地址與電話比對，見 `research/scripts/renames.py`。
- **等候資訊確定不存在於任何公開來源**：不只各中心沒公布，連縣市衛生局的彙整頁也只有電話。這是本題最想解決的痛點，但資料端補不上。
