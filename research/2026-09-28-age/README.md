  同日下午重試仍取不到：`POST /cecm/screenView/form` 與 `/cecm/` 首頁每次 45 秒逾時（5 次，間隔 30–150 秒遞增），`www.sfaa.gov.tw` 同樣逾時，改從另一條外部線路抓則被拒絕連線（ECONNREFUSED）；
